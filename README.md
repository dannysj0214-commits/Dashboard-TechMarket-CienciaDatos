## 📝 Descripción del Proyecto
Este proyecto aplica técnicas de Ciencia de Datos (limpieza, transformación, modelado y visualización) sobre el archivo histórico de ventas `ventas_techmarket.csv` de la empresa TechMarket S.A.

El objetivo principal es construir un Dashboard Analítico que responda a las preguntas de negocio del gerente general, permitiendo identificar productos más vendidos, ventas por región, tendencias mensuales y participación por categoría.

## 🛠️ Tecnologías Utilizadas
*   **Python 3**
*   **Pandas** (Limpieza y manipulación de datos)
*   **Matplotlib** y **Seaborn** (Visualización de datos)
*   **Jupyter Notebook** en Visual Studio Code

## 📂 Estructura del Proyecto
*   `Dashboard_TechMarket.ipynb`: Cuaderno principal con el código de análisis, modelo estrella y generación de gráficos.
*   `ventas_techmarket.csv`: Dataset original simulado (incluye datos nulos y duplicados para demostrar la limpieza).
*   `dashboard_techmarket.png`: Imagen final del dashboard consolidado con los 4 gráficos (anillo, barras, líneas).

## 📈 Metodología
1. Carga y exploración de datos.
2. Limpieza (valores nulos, duplicados, fechas).
3. Cálculo de KPIs (ventas totales, promedios).
4. Modelo Estrella (Tabla de hechos + Dimensiones).
5. Generación de visualizaciones.
